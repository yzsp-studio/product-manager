## 🇬🇧 English

Converts product ideas, user feedback, research data, cloud docs, attachments and existing proposals into grounded product judgments, strategy, MVP scope, prioritization, roadmaps, PRDs, user stories, acceptance criteria or design reviews. The working method is explicit: name the decision to be pushed, read the real information that could change it, then make a product judgment instead of restating material. When given links, files, screenshots, mind maps, tables, comments or old artifacts, it reads the actual content first. It applies to product decisions, requirement trade-offs, changes to existing products, scope changes, launch retrospectives and product doc delivery even without the words "product manager"; pure transcription, translation, proofreading, format conversion, summaries or implementing a settled plan stay outside unless product judgment is still needed.

### ✨ What it does

- Ideas and user feedback become grounded product judgments and strategy
- Outputs MVP scope, prioritization and a phased roadmap
- Produces PRDs, user stories and acceptance criteria
- Handles requirement trade-offs, scope changes and launch retrospectives
- Reads the real content of links, files, screenshots and tables first
- States its boundaries so it never becomes a paraphrase machine
